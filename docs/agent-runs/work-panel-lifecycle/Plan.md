# 桌寵啟動與降級第二階段

使用者於 2026-09-13 授權依長期修正計畫實作。沿用現有 dirty work，禁止提交 private state。Launcher 管理 lifecycle，Electron 管理展示；中央語音的常駐由語音專案管理。

1. 移除中央語音對 LLM 啟動的硬依賴；健康檢查不合成音訊，失敗保留文字與回合完成。驗證離線、逾時與恢復。
2. Launcher 提供版本、期望狀態、失敗原因及有上限的恢復；明確停止後不自動復活。面板呈現各項能力及重試。驗證並行、失敗预算、手動停止、舊版本。
3. 角色設定仍以 Launcher/catalog 為準，Electron 經限制目錄的本機 protocol 載入既有模型；不得複製權重或把 token 傳給 renderer。驗證無 LLM 模型載入、路徑邊界、切換角色。
4. 啟動／螢幕變更／模型 ready 後修正不可見位置；保留正常位置。驗證多螢幕、負座標、不同尺寸。
5. 中央語音提供獨立常駐入口與登入啟動，使用既有環境；不由 Kuro 終止共用服務。
6. targeted tests、renderer check/build、隔離故障 smoke，再以正式 VBS 重新載入驗收。正式結果與隔離結果分開記錄；失敗先修正，未驗證不標完成。

使用者追加決策：舊版不需相容。本輪移除舊控制台的啟動／喚回分支與 LLM 模型 HTTP 回退；工作面板是唯一日常入口，保留 Qt 內部背景管理、既有資料及其他任務的 dirty source。完成結果見 `Progress.md` 第二階段。
