# 形成授權契約 v2

此版本延伸 11/23 M0 對 scoped_auto 的預設關閉行為。現有 explicit 與 manual 行為繼續使用原契約。v2 的新增授權限於 Qt 原生確認所顯示的角色、專案、來源、記憶類型與保存範圍，更新須匹配先前規則的 digest。政策僅控制後續完成的使用者發言。歷史加工需獨立選擇來源範圍。

- 保存自然發言須驗證來源 turn、history、角色及當時政策。候選或生成文字無法代表人工同意。政策變動時，待處理回合須降回候選或重新核對。
- L2 由可撤回的 History 來源衍生；L3 的來源、類型、授權及內容由 Repository 與 lifecycle 綁定。停用、替代與遺忘應在進入 prompt 以前執行。
- 助理文字、工具結果、MCP 回應與文件不得獲得使用者自述授權。外部 domain 的現況與更動權仍屬原 owner。
- 本次只在 synthetic 根測試新模式。正式環境的新增授權數為零。
- 舊角色庫若以角色 ID 代替未知專案 ID，資料留在原庫供人工管理。使用者未指定專案、指定同名專案或切到其他專案時，均不得把它注入對話或透過自然語句撤回其他範圍的資料。
