# Synthetic Qt 預覽截圖

此目錄只保存本輪 Qt Widgets `QWidget.grab()` 的合成預覽，不含私人聊天、股票或來源資料。
1280 × 720 圖為 Qt offscreen 實際 render；不是桌面 runtime、正式 Qt controller 或產品驗收證據。

原定 `docs/agent-runs/kuro-work-companion-ui-v0-v1-20261010/` 的父目錄在 sandbox 及審核後的命令均回報 `UnauthorizedAccessException`。
因此文件與截圖改存這個新建、任務專用的 devtools 目錄；沒有變更 ACL。
